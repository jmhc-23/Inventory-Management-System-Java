## 📌 Project Overview
The **Inventory Management System** is a console-based Java application created to practice and apply **Core Java and OOP concepts**.

The application allows managing inventory items and searching them using keywords such as name, category, or storage location.

This is **Task 1** of a step-by-step project that will be further developed using **Spring Framework** and **Spring Boot**.

## 🎯 Why I Built This Project
- To strengthen my understanding of Core Java
- To practice Object-Oriented Programming in a real use case
- To build a base project that can be upgraded to Spring and Spring Boot

## ⚙️ Key Features
- Add inventory items
- View all items
- Keyword-based search by:
    - Item name
    - Category
    - Storage place
- Simple and readable code structure
